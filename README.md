# Doris & Dora International School website

This is a complete Next.js version of the school website using the photos and logo supplied in the chat.

## Run it

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open http://localhost:3000

## Before publishing

Replace the three placeholder contact items in `app/page.tsx` with the school's official:
- Phone number
- WhatsApp number
- Email address

The site already includes:
- Responsive navigation
- Full-screen photo hero
- School logo and motto
- About section
- Programs/features
- School life
- Photo gallery
- Admissions/contact section
- Mobile layout
